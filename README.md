# Eq — системный эквалайзер для Android

Минималистичный аудио-эквалайзер, который применяет настройки ко **всему звуку устройства** (музыка, видео, игры, YouTube) через глобальную аудио-сессию Android — не только к одному плееру.

## Возможности

- **5 полос эквалайзера** — полосы берутся из возможностей конкретного устройства (`Equalizer.getNumberOfBands()`), диапазоны частот отображаются как есть (например 60 Гц … 14 кГц).
- **Усиление громкости (boost)** — общий подъём уровня до **+15 дБ** через `LoudnessEnhancer`. Понижение громкости не предусмотрено.
- **Включение/выключение** одним переключателем — эффект применяется к глобальному выходу (`sessionId = 0`).
- **Сохранение настроек** — уровни полос, усиление и состояние включаются/выключения хранятся в `SharedPreferences` и восстанавливаются при запуске.
- **Отказоустойчивость** — если прошивка устройства запрещает доступ к глобальной аудио-сессии (частая ситуация на Android 10+), приложение показывает информационную карточку вместо краха.

## Скриншот-описание интерфейса

Вертикальный экран в стиле Material 3:
- заголовок «Эквалайзер» с переключателем On/Off;
- карточка с вертикальными слайдерами полос (от −15 до +15 дБ) и подписями частот;
- карточка «Усиление громкости» с отдельным слайдером 0…+15 дБ;
- при недоступности глобальной сессии — карточка с пояснением.

Аудио-эффекты: `android.media.audiofx.Equalizer`, `android.media.audiofx.LoudnessEnhancer`.

## Права доступа

- `MODIFY_AUDIO_SETTINGS` — требуется для управления эквалайзером и усилением. Никаких других разрешений приложение не запрашивает; интернет-доступа нет.

## Сборка

Требуется JDK 17 и Android SDK (compileSdk 35).

```bash
./gradlew assembleDebug
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Структура проекта

```
app/src/main/java/eq/app/
├── MainActivity.kt          # входная точка, Compose-активити
├── EqualizerController.kt   # обёртка над Equalizer + LoudnessEnhancer
├── EqualizerScreen.kt       # UI на Compose/Material 3
├── EqPrefs.kt               # сохранение настроек (SharedPreferences)
└── ui/theme/Theme.kt        # тема приложения
```

## Ограничения

- Глобальная сессия (`sessionId = 0`) может быть заблокирована производителем — на части устройств Android 10+ эффект не применится; приложение честно сообщит об этом.
- Усиление работает только вверх (0…+15 дБ) — это ограничение `LoudnessEnhancer`.
- Количество и частоты полос зависят от аудио-тракта устройства.
