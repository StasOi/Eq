# Eq — системный эквалайзер для Android

Минималистичный аудио-эквалайзер, который применяет настройки ко **всему звуку устройства** (музыка, видео, игры, YouTube) через глобальную аудио-сессию Android — не только к одному плееру.

## Возможности

- **5 полос эквалайзера** — полосы берутся из возможностей конкретного устройства (`Equalizer.getNumberOfBands()`), диапазоны частот отображаются как есть (например 60 Гц … 14 кГц).
- **Пресеты** — Flat, Bass Boost, Rock, Pop, Jazz, Classical, Vocal, Treble; кривые интерполируются на фактическое число полос устройства. Ручное перемещение ползунка переключает пресет в «Пользовательский».
- **Bass Boost и Virtualizer** — регулировка 0…100 % через `BassBoost` и `Virtualizer`.
- **Усиление громкости (boost)** — общий подъём уровня до **+15 дБ** через `LoudnessEnhancer`. Понижение громкости не предусмотрено.
- **Включение/выключение** одним переключателем — эффект применяется к глобальному выходу (`sessionId = 0`), состояние сохраняется.
- **Фоновая работа** — foreground-сервис с постоянным уведомлением «EQ активен» в статус-баре; эффект продолжает работать после закрытия приложения. В уведомлении есть кнопка быстрого Включить/Выключить.
- **Визуализация уровня громкости** — осциллограмма в реальном времени через `Visualizer` (требуется разрешение «Микрофон», включается отдельным переключателем).
- **Тёмная/светлая тема** — кнопка в шапке циклически переключает Системная → Светлая → Тёмная; выбор сохраняется.
- **Список аудиоэффектов системы** — приложение регистрирует обработчик `DISPLAY_AUDIO_EFFECT_PANEL_CONTROL` и доступно из системного списка «Аудиоэффекты».
- **Сохранение настроек** — уровни полос, пресет, эффекты и темы хранятся в `SharedPreferences` и восстанавливаются при запуске.
- **Адаптивная иконка** (включая тематическую на Android 13+).
- **Отказоустойчивость** — если прошивка устройства запрещает доступ к глобальной аудио-сессии (частая ситуация на Android 10+), приложение показывает информационную карточку вместо краха.

Аудио-эффекты: `android.media.audiofx.Equalizer`, `LoudnessEnhancer`, `BassBoost`, `Virtualizer`, `Visualizer`.

## Права доступа

- `MODIFY_AUDIO_SETTINGS` — управление эквалайзером и эффектами.
- `RECORD_AUDIO` — только для визуализации; без него работает всё остальное.
- `POST_NOTIFICATIONS` — постоянное уведомление «EQ активен» (Android 13+).
- `FOREGROUND_SERVICE(_MEDIA_PLAYBACK)` — фоновая работа эффектов.

Интернет-доступа нет.

## Сборка

Требуется JDK 17 и Android SDK (compileSdk 35).

```bash
./gradlew assembleDebug    # debug APK
./gradlew assembleRelease  # подписанный release APK
```

Debug APK: `app/build/outputs/apk/debug/app-debug.apk`.
Release APK: `app/build/outputs/apk/release/app-release.apk`.

Для подписи release создайте `keystore.properties` в корне проекта:

```properties
storeFile=<путь к .jks>
storePassword=<пароль>
keyAlias=<алиас>
keyPassword=<пароль>
```

Файл и сам keystore исключены из git (`.gitignore`) — храните их отдельно.

## Ограничения

- Глобальная сессия (`sessionId = 0`) может быть заблокирована производителем — на части устройств Android 10+ эффект не применится; приложение честно сообщит об этом.
- Усиление работает только вверх (0…+15 дБ) — это ограничение `LoudnessEnhancer`.
- Количество и частоты полос зависят от аудио-тракта устройства.
- Разрешение «Микрофон» запрашивается `Visualizer`-API для захвата сигнала — это требование Android, реальная запись микрофона не производится.
